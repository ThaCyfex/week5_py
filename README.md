# Week5_Py 🐍✨

## Week 5 Assignment: Python OOP Concepts 🐍✨

### Description
This repository contains the solution to the Week 5 assignment, showcasing the fundamentals of Object-Oriented Programming (OOP) in Python. It features concepts such as class design, constructors, inheritance, encapsulation, and polymorphism.

The program includes:
- A **Superhero class**, with a subclass **Kryptonian**, highlighting inheritance and polymorphism.
- An **Animal class**, with subclasses **Bird**, **Fish**, and **Dog**, demonstrating polymorphic behavior through unique `move()` methods.

---

### Features
- **Superhero Module**:
  - Define general and Kryptonian-specific superheroes.
  - Demonstrate OOP concepts like inheritance and polymorphism.
- **Polymorphism Challenge**:
  - Represent animals with varied behaviors using a common interface (`move()`).
- **Dynamic Design**:
  - Utilize constructors to create unique objects.
  - Override methods for customized functionality.
